# Учебный проект — JavaFX (два задания)

Проект содержит два независимых экрана, оба запускаются из общего стартового окна `LauncherApp`.

## Задание 1 — `CalculatorApp` ("Отработка Ввода/Вывода")

Форма повторяет макет: заголовок «Отработка Ввода/Вывода», подзаголовок с формулировкой
задачи, два поля-аргумента, кнопка «Вычислить:» и панель результата
(в макете показан пример `5 + 6 = 11`, `5 * 6 = 30`; в реализации — сложение и вычитание,
как требует текст задания).

## Задание 2 — `ListEditorApp` ("Редактирование списка")

Форма повторяет макет: заголовок «Редактирование списка», поле «Введите имя:»,
кнопки «Добавить в список» / «Проверить на символы» / «Удалить выбранное»,
панель «Список имён:». При обнаружении недопустимых символов показывается
модальное окно **«Внимание: Есть не текстовые символы, очистить?»** с кнопками
**Очистить** (зелёная, убирает лишние символы и вставляет) и **Оставить**
(красная, вставляет как есть, лишние символы не трогает).

## Реализованная функциональность (Задание 2, полный список)

1. **Добавление элемента в список.**
   Ввод — только через кнопку «Добавить» или Enter в поле ввода.
   Прямое редактирование списка (вписывание текста прямо в ListView) не предусмотрено — запрещено по условию задания.

2. **Удаление данных.**
   Кнопка «Удалить» удаляет выбранный элемент из списка.

3. **Подсветка выбранного элемента.**
   При клике на элемент списка он подсвечивается штатным выделением `ListView`.

4. **Навигация по списку клавишами со стрелками (`*`).**
   Стрелки ↑ / ↓ переключают выделение между элементами списка.

5. **Отмена вставки по `Ctrl+Z` (`**`).**
   Последняя добавленная запись удаляется из списка при нажатии Ctrl+Z.

6. **Нормализация данных.**
   - Удаляются все пробелы — перед словом, после слова и внутри слова.
   - Имя приводится к формату «первая буква заглавная, остальные строчные»,
     независимо от регистра ввода (например, если случайно включён CapsLock).
   - Проверено на примере: `ИнноКЕнТиЙ` → `Иннокентий`.

7. **Поиск недопустимых символов.**
   Кнопка «Проверить на «лишние» символы» и автоматическая проверка при добавлении:
   если в тексте есть цифры, знаки препинания, скобки, арифметические знаки и т. п.,
   выводится модальное окно с перечнем найденных символов.
   Разрешены только буквы и дефис (для составных имён вида «Анна-Мария»).

8. **Исключение дубликатов.**
   При попытке добавить имя, которое уже есть в списке (после нормализации),
   выводится модальное окно «Уже есть в списке» → OK, вставка не производится.

## Технологии

- Java 17+
- JavaFX 21 (модуль `javafx-controls`)
- Сборка — Maven (`javafx-maven-plugin`)

## Структура проекта

```
NameListApp/
├── pom.xml
├── README.md
└── src/main/java/
    ├── module-info.java
    └── com/kapkir/namelist/
        ├── LauncherApp.java           — стартовое окно выбора задания
        ├── CalculatorApp.java         — Задание 1: сложение/вычитание
        ├── ListEditorApp.java         — Задание 2: список имён
        ├── NameNormalizer.java        — нормализация и валидация строк
        └── ObservableListWrapper.java — обёртка над списком имён
```

## Сборка и запуск

Требуется установленный JDK 17+ и Maven.

```bash
mvn clean javafx:run
```

Либо собрать jar и запустить вручную (потребуется указать JavaFX SDK в module-path):

```bash
mvn clean package
```
